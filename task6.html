CSS Image Properties

This webpage demonstrates different CSS properties used to control images, including size, shape, position, opacity, borders and shadows.

Image 1 — Normal Rectangular Image

This is a normal rectangular image. It demonstrates width, height, border, border-radius and box-shadow.

Image 2 — Circular Profile Image

This image is made circular using border-radius: 50%. It can be used as a profile picture.

Image 3 — Fixed Size with Object-Fit

This image has a fixed width and height. The object-fit property controls how the image fits inside the fixed-size box.
